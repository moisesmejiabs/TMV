# Project Instruction Directory

This is the known location for durable, project-specific Codex instructions.

The repository-root `AGENTS.md` must instruct Codex to read every Markdown file
in this directory before changing files, running project commands, or proposing
a deployment.

Do not store credentials or secret values here.

For this project, read `ProjectInstructions.md` before making changes. Also
review `Documentation/Deployment.md` before any release and
`Documentation/Operations.md` before changing production data or bindings.
